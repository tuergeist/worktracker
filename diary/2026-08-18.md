# 2026-08-18

## Range-carry precision + login persistence

Two small follow-ups from the Pläne feature and general usage feedback.

### Changes Made

**Frontend:**
- `frontend/js/plans.js`: added `step: 5` to the Range plan's carry-distance fields (`i7`/`i5` in Wechselblock, `sw9`/`aw9` in Teildistanzen) and rendered it as the `step` attribute on the number inputs. Trigger: on a driving range you can only read carry off the distance markers to about 5m precision, so entering e.g. "128.5m" was fake precision. This matches the app's existing convention — `range.js`'s slider (`range-slider` in `index.html`) already uses `step="5"` for the same reason.

**Backend:**
- `backend/users.py`: session cookie + JWT lifetime was `86400` seconds (24h, both `cookie_max_age` and `JWTStrategy.lifetime_seconds`). User trains every 2-4 days and was getting logged out between sessions. Bumped both to `SESSION_LIFETIME_SECONDS = 90 * 24 * 60 * 60` (90 days) — this is a personal training log, not something that needs bank-grade session expiry.

### Verification
- Confirmed the `step="5"` attribute rendered correctly by curling the deployed `/js/plans.js` from a local `docker compose` stack and checking the generated field-HTML template.
- Session-lifetime change is a straightforward constant bump, not independently browser-tested (would require waiting out the old vs. new expiry).

### Notes
- Initially suspected a second cause: `SESSION_SECRET` falling back to a random per-process value if unset in the real k8s secret, which would invalidate all sessions on every redeploy independent of cookie lifetime. **User corrected this**: `SESSION_SECRET` in the live scratchlab cluster is already a properly generated 64-char hex secret, not the `CHANGE_ME` placeholder from `k8s/secret.example.yaml` — only the repo template looks unset. Rotating it would kill every session for no benefit, so left untouched. The 24h→90-day cookie/JWT lifetime fix in `backend/users.py` is the actual and complete fix here; it just needs a rebuild+redeploy to take effect.
